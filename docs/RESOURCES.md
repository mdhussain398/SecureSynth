## Data
- **No external datasets.** All data is generated by `backend/ml/generate.py` (seeded) and `backend/app/seed.py`.
- **Synthetic geography:** city coordinates are approximate public city-centre values, used only to compute distances.

## Development tools and AI assistance
- **AI-assisted development (permitted, per the team's confirmation with the organisers):** the team used Claude Code (Anthropic) to help write code, tests and documentation during the event.
- **Team responsibility:** design decisions, review and the live demonstration are the team's. Every team member is expected to be able to explain the design.
- **Runtime:** the product itself calls no AI or LLM service.
- **Tooling:** Homebrew Python 3.12, Node.js, Git/GitHub.
